# miguelsoeiro.github.io

Site pessoal estático (HTML, CSS e JavaScript simples, sem dependências).

## Publicar no GitHub Pages

1. Cria no GitHub um repositório público com o nome exato **`miguelsoeiro.github.io`**
   (o nome tem de coincidir com o teu utilizador do GitHub).
2. Coloca nele estes ficheiros na raiz: `index.html`, `style.css`, `app.js`, `data.js`, `.nojekyll`.
3. Em *Settings → Pages*, escolhe *Deploy from a branch* → `main` → `/ (root)`.
4. Em cerca de um minuto o site fica em https://miguelsoeiro.github.io

## Atualizar conteúdos

Edita apenas o `data.js`: carreira, percurso académico, artigos de opinião, vídeos e publicações.
Nos vídeos, em `youtube` coloca só o ID (o que vem depois de `v=` no endereço) para aparecer a miniatura.

## Domínio próprio (mais tarde)

Quando registares o domínio, cria um ficheiro `CNAME` na raiz com uma só linha (por exemplo `miguelsoeiro.me`),
configura no registador os registos DNS indicados na documentação do GitHub Pages e ativa *Enforce HTTPS*.
